# MechWar-X
## Robot Rental Management Database System
MechWar-X is a database management application developed for a class project. The system manages robots (mechs), clients, rental reservations, and maintenance records.

## Technologies Used
- Python
- Streamlit
- MySQL Server & Workbench
- VS Code

## Application Features
There are four tabs: Mech Registration, Client Dashboard, Rental Scheduling, and Maintenance.
1. Mech Registration: Used to register the robots and manage information about them such as year, model, etc.
2. Client Dashboard: Used to search for clients and view their rental history.
3. Rental Scheduling: Creates reservation and precents overbooking of robots.
4. Maintenance: Reports, tracks, and resolves maintenance issues.
